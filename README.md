# Awesome Jev Resources

A curated list of Jev guides, official documentation, and community projects for AI practitioners, product managers, and builders.

Jev is TypeSafe's System One model for fast, structured decisions. Give it information and a defined question; get a choice, score, or probability your software can use.

## Start here

1. **[What is Jev? Costs, examples, and getting started — Karo Zieminski, Product with Attitude](https://karozieminski.substack.com/p/what-is-jev-cost)** — A practical introduction to Jev, how it differs from LLMs, and what you can build with it.

## Official documentation

- **[TypeSafe documentation](https://docs.typesafe.ai/introduction)** — The official introduction to Jev and System One models.
- **[Quick start](https://docs.typesafe.ai/introduction/quickstart)** — Get started with the playground, API, Python SDK, or coding-agent skill.
- **[Question types: Choice, Score, and Noul](https://docs.typesafe.ai/primitives)** — Define the decisions you need and understand the structured answers.
- **[Confidence](https://docs.typesafe.ai/confidence)** — Understand confidence and how to use it when deciding whether to act on an answer.

## Community projects and demos

- **[Jevable](https://jevable.com/)** — Discover what people are building with Jev. Browse demos and examples for inspiration.

### Jev integrations and AI agent tools

- **[browser-use/jev-ultrafast](https://github.com/browser-use/jev-ultrafast)** — Jev browser automation agent that selects actions and page elements, calling an LLM only when text generation is needed.
- **[tamaratran/fast-jev-compaction](https://github.com/tamaratran/fast-jev-compaction)** — Jev context compaction for Claude Code: score tool calls and results, drop stale context, and preserve retained content verbatim.
- **[jarrodwatts/jev-trader](https://github.com/jarrodwatts/jev-trader)** — Jev crypto trading bot that chooses buy or sell from Kuru order-book data on Monad, with a dry-run mode and live dashboard.
- **[kerpopule/hermes-jev-skills](https://github.com/kerpopule/hermes-jev-skills)** — Jev skills for AI agents: model routing, memory filtering, context selection, skill selection, search, and browser automation.
- **[devagrawal09/jev-review](https://github.com/devagrawal09/jev-review)** — Jev code review for Git diffs and codebases, using structured decisions to select evidence, assess risks, and score severity.
- **[thruwire/foreman](https://github.com/thruwire/foreman)** — Jev supervisor for Codex and OpenCode agents that assesses progress, tests, and completion to steer, retry, verify, or stop work.
- **[superagents-lab/jev-search](https://github.com/superagents-lab/jev-search)** — Jev web search app that selects sources, queries, and time ranges, then ranks Search1API results by relevance.
- **[socai-io/jev-social](https://github.com/socai-io/jev-social)** — Jev social media research agent using socai to search Instagram, TikTok, and LinkedIn and collect source-linked evidence.
- **[droidrun/mobile-jev](https://github.com/droidrun/mobile-jev)** — Jev Android automation agent that selects app actions through Mobilerun, with a live dashboard, CLI, and execution traces.
- **[gargpratyush/jev-router](https://github.com/gargpratyush/jev-router)** — Jev model router for Claude Code and OpenAI Codex that selects a model for each new turn based on task complexity.

### Local decision model alternatives

- **[SemIf (formerly OpenJev)](https://github.com/TheoLeeCJ/SemIf-OpenJev)** — Independent, open-source Jev-style decision interface for running typed AI decisions locally with open models.
